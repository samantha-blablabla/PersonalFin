# Session Logs

Thư mục này chứa logs của các session làm việc với Claude Code.

## Mục đích
- Theo dõi tiến độ phát triển
- Ghi nhận các quyết định kỹ thuật
- Token usage tracking
- Backup thông tin quan trọng

## Format
- **File naming**: `SESSION_YYYY-MM-DD.md` (hoặc `SESSION_YYYY-MM-DD_N.md` nếu có nhiều session trong ngày)
- **Nội dung**: Markdown format với các section chuẩn
